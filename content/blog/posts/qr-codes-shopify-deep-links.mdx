## What Are Shopify Deep Links?

A Shopify deep link is a URL that opens a specific screen inside a native app experience — a product page, a pre-filled cart, a collection, or a checkout screen — instead of dropping the user on your generic website homepage.

There are three different types depending on your setup:

| Destination | What it opens | Best for |
|---|---|---|
| Shop App (`shop.app`) | Shopify's native consumer app | Stores without a custom brand app |
| Your custom brand app | Your own iOS or Android app | Brands with a dedicated app |
| Web cart with URL params | Pre-filled mobile web cart | Any store, no app needed |

## Building Your Shopify Deep Link URLs

### Link to a Product Page

If you are using the Shop App (works for any Shopify store):

```
https://shop.app/p/your-product-handle
```

If you have your own custom brand app:

```
https://yourstore.com/products/your-product-name
```

This URL acts as a Universal Link on iOS and an App Link on Android once your app is configured. See the [iOS Universal Links guide](/blog/ios-universal-links-complete-guide) and [Android App Links guide](/blog/android-app-links-setup-guide) if you haven't done that setup yet.

### Pre-Fill a Cart With Products and Discounts

This is the most powerful format for QR code campaigns. Shopify supports pre-filling carts directly through the URL:

```
https://yourstore.com/cart/VARIANT-ID:QUANTITY?discount=YOURCODE
```

Real examples:

```
Single product with discount:
https://yourstore.com/cart/41234567890:1?discount=SUMMER26

Multiple products:
https://yourstore.com/cart/41234567890:1,41234567891:2?discount=SUMMER26
```

To find the variant ID for your product, go to Shopify Admin, open your product, click on a variant, and look at the number at the end of the URL.

### Link to a Collection

```
https://yourstore.com/collections/summer-sale
```

Good for seasonal campaigns where you want to show the full range rather than a single product.

## Building QR Codes That Actually Work

This is where most merchants go wrong. The type of URL you encode in a QR code matters enormously.

### The Wrong Way: Custom URI Schemes

```
myshopifyapp://product/123
```

Do not do this. Custom URI schemes inside QR codes fail silently when scanned with iOS Camera, Google Lens, or any desktop scanner. They only work if the app is already open, which defeats the purpose.

### The Right Way: A Smart HTTPS URL

Always encode an `https://` URL in your QR code. A smart link handles all the routing decisions after the scan:

```
https://dlnk.co/your-store/product-name
```

When someone scans this code, the smart link:

1. Detects whether they are on iOS, Android, or a desktop
2. Checks whether your app is installed on their device
3. Opens your app directly if it is installed
4. Sends them to the App Store or Play Store if it is not
5. Opens your mobile web page if they are on a desktop

The QR code itself is just a container. All the intelligence lives in the smart link.

### Dynamic QR Codes vs Static QR Codes

| What you are comparing | Static QR code | Dynamic QR code |
|---|---|---|
| URL encoded in the code | Your actual destination URL | A redirect URL you can change |
| Can update destination later | Never | Any time |
| Scan analytics available | No | Yes |
| Need to reprint if destination changes | Yes | No |

Always use dynamic QR codes. They encode a redirect URL, usually a smart link like one from DeepLinkOS, that you can update at any time without reprinting. If you run a static QR code to a seasonal sale page, you cannot change it when the sale ends.

## Running a QR Code Campaign Step by Step

### Step 1: Create Your Shopify Deep Link

Build the cart URL with your product variant ID and discount code:

```
https://yourstore.com/cart/41234567890:1?discount=LAUNCH26
```

This opens the native app with the product in the cart and the discount code already applied.

### Step 2: Wrap It in a Smart Link

In DeepLinkOS, create a smart link and set:

- iOS destination: your brand app Universal Link or `shop.app`
- Android destination: your brand app App Link
- iOS fallback (no app): your App Store listing
- Android fallback (no app): your Google Play listing
- Desktop fallback: your product web page

### Step 3: Generate a Dynamic QR Code

Encode your short smart link URL into a QR code. The QR code stays the same forever. If you need to change the destination, you update the smart link. No reprinting.

### Step 4: Add UTM Parameters for Tracking

```
https://dlnk.co/launch-sale?utm_source=print&utm_medium=flyer&utm_campaign=aug-launch
```

This tells you exactly how many purchases came from each physical location your QR code appears on.

## Frequently Asked Questions

### Do Shopify cart deep links still work if the user doesn't have the app?

Yes. If the user doesn't have your app, the smart link falls back to your mobile web cart URL — which still has the product pre-filled and the discount applied. Native app is the best experience, mobile web is the reliable fallback.

### Can I use QR codes in TikTok or Instagram videos?

QR codes shown in videos can be scanned with iOS Camera or Google Lens if they are visible for at least two seconds and large enough on screen. This is increasingly common in creator product placements and sponsored content.

### Where do I find the variant ID for my Shopify product?

Go to Shopify Admin, open Products, select your product, then click on a specific variant. The variant ID is the number at the end of the URL in your browser. You can also pull all variant IDs for a product via the Shopify Admin API.

### Does the Shop App link work for all Shopify stores?

Yes. Every Shopify merchant is supported by the Shop App automatically. The `shop.app/p/your-product-handle` URL works out of the box. You don't need your own iOS or Android app to get native checkout conversion improvements.

### How big does a QR code need to be to scan reliably?

A minimum of 2cm by 2cm for printed materials viewed at arm's length. For outdoor advertising, use roughly 1cm of QR code size for each meter of viewing distance. Use Level H error correction (the highest setting) for anything printed physically, since wear and low lighting reduce scan accuracy.
