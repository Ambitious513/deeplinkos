TikTok sends more mobile traffic than almost any other platform — but most of that traffic leaks. Users tap your link, land inside TikTok's locked-down in-app browser, get asked to log in again, and give up. The checkout completion rate drops 25–40% compared to native app experiences.

TikTok deep links fix this. A properly built TikTok deep link detects the platform, breaks out of the in-app browser, and routes users directly into your native app. Here's exactly how to build one.

## What Is a TikTok Deep Link?

A **TikTok deep link** is a smart URL that navigates users from TikTok content — videos, bio links, ads — directly into a specific screen of a native mobile app, bypassing the browser entirely.

There are two scenarios:

1. **Linking into the TikTok app itself** — to a profile, video, or sound (e.g., `tiktok://user?username=deeplinkos`)
2. **Linking from TikTok to your external app** — sending TikTok traffic into your iOS/Android app (the harder, more valuable case)

This guide covers both, with a heavy focus on scenario 2.

## Why TikTok's In-App Browser Kills Conversions

When users tap a link in TikTok, the app opens it inside an isolated `WKWebView` (iOS) or `WebView` (Android). This sandboxed container has three critical problems:

| Problem | Impact |
|---|---|
| Empty cookie state | Users are logged out of Shopify, Amazon, Spotify, etc. |
| JS redirect blocking | `window.location = "myapp://"` is silently ignored on iOS |
| No payment autofill | Apple Pay and Google Pay don't work |

> **The data:** 88% of mobile time is spent in native apps. Users who land in a native app convert 3× better than users stuck in a webview. Every link that opens in TikTok's browser costs you that lift.

## The Platform-Detect-Route-Fallback (PDRF) Method

DeepLinkOS uses the **Platform-Detect-Route-Fallback (PDRF) method** for TikTok traffic — the only approach that handles all four device states reliably:

1. **Detect** — identify TikTok's in-app browser via User-Agent
2. **Platform split** — different routing for iOS vs Android
3. **Route** — send to the correct deep link format
4. **Fallback** — handle the "app not installed" case gracefully

### Step 1 — Detect TikTok's In-App Browser

TikTok's webview exposes itself in the User-Agent string:

```javascript
const isTikTokBrowser = /musical_ly|TikTok/i.test(navigator.userAgent);
const isIOS = /iPhone|iPad|iPod/i.test(navigator.userAgent);
const isAndroid = /Android/i.test(navigator.userAgent);
```

### Step 2 — iOS Routing: Universal Link + User Gesture

iOS WebKit blocks automatic URI scheme launches. The only reliable method is pairing a Universal Link with an explicit user tap:

```html
<!-- This button must be tapped — no auto-redirect on iOS TikTok -->
<a href="https://yourapp.com/product/123"
   id="open-app-btn"
   style="display:block; padding:16px; background:#ef7a22; color:#fff; text-align:center;">
  Open in App
</a>
```

When the user taps this button, iOS intercepts the `https://yourapp.com` domain (because your AASA file is configured — see the [iOS Universal Links guide](/blog/ios-universal-links-complete-guide)) and opens your app directly.

### Step 3 — Android Routing: Intent URI

Android supports `intent://` URIs inside TikTok's WebView, making routing more direct:

```javascript
if (isAndroid) {
  const intentUri = [
    'intent://yourapp.com/product/123#Intent;',
    'scheme=https;',
    'package=com.yourapp.android;',
    'S.browser_fallback_url=https://play.google.com/store/apps/details?id=com.yourapp.android;',
    'end;'
  ].join('');
  window.location.href = intentUri;
}
```

The `S.browser_fallback_url` parameter ensures users without the app go to the Play Store — not a broken page.

### Step 4 — Fallback Pages

Always build fallback pages for both stores:

```
iOS fallback:     https://apps.apple.com/app/id[YOUR_APP_ID]
Android fallback: https://play.google.com/store/apps/details?id=[PACKAGE_NAME]
Desktop fallback: https://yourapp.com (web version)
```

To send users from your app or web into TikTok's native app:

```
# Open a TikTok user profile
tiktok://user?username=deeplinkos
https://www.tiktok.com/@deeplinkos (Universal Link fallback)

# Open a specific TikTok video
tiktok://video?id=7123456789012345678
https://www.tiktok.com/@user/video/7123456789012345678

# Open TikTok for You page

```

Always include an `https://` fallback URL — the URI scheme only works if TikTok is installed.

## Common Mistakes and Fixes

### ❌ Mistake 1: Auto-redirect on page load

```javascript
// This is silently blocked by iOS WebKit inside TikTok
window.location.href = "myapp://product/123";
```

✅ **Fix:** Use a user-initiated button tap with Universal Link — never auto-redirect.

### ❌ Mistake 2: Using only the custom URI scheme

```
myapp://product/123
```

✅ **Fix:** Use `https://` Universal Links as the primary route. Custom schemes are unreliable and fail silently when the app isn't installed.

### ❌ Mistake 3: Sending traffic to standard web checkout

✅ **Fix:** All TikTok traffic should go through a smart router that attempts native app launch first. Web checkout should only be the last-resort fallback.

### ❌ Mistake 4: No attribution on deep link traffic

✅ **Fix:** Append UTM parameters to every TikTok smart link: `?utm_source=tiktok&utm_medium=bio&utm_campaign=summer26`. For a full breakdown of how to recover attribution data lost at the App Store, see [UTM vs Smart Attribution](/blog/utm-vs-smart-attribution).

## Frequently Asked Questions

### Do TikTok deep links work for TikTok Shop?

Yes. TikTok Shop product links support deep linking into the native TikTok app's shopping tab. For external Shopify/WooCommerce stores, you still need the PDRF routing approach above.

### Can I use a link shortener for TikTok bio links?

Yes, but use a branded short domain (e.g., `dlnk.co/handle`) rather than `bit.ly`. Branded links increase click-through rates by 34% and don't trigger TikTok's "external link" warning as aggressively.

### Why does my deep link work in Chrome but not TikTok?

Chrome is a full browser. TikTok's in-app browser is a sandboxed WebView with stricter JS and Universal Link handling. The PDRF method solves this gap.

### Do TikTok deep links work in TikTok ads?

For TikTok paid ads, use the Measurement URL field for attribution tracking and the Destination URL field for the user-facing landing page. Smart routing applies the same way.

### How do I track TikTok deep link conversions?

Use DeepLinkOS smart links with UTM parameters + the TikTok Pixel on your web fallback page. For app conversions, connect to your MMP (AppsFlyer, Adjust, Branch) via the SDK.
