## What Is a TikTok Deep Link?

A TikTok deep link is a smart URL that takes users from TikTok content — videos, bio links, ads — and sends them directly into a specific screen of your mobile app without going through a browser first.

There are two different things people mean when they say "TikTok deep link":

1. **Linking into TikTok** — sending someone to a specific TikTok profile or video (like `tiktok://user?username=deeplinkos`)
2. **Linking from TikTok into your app** — sending TikTok traffic into your own iOS or Android app

This guide focuses mainly on the second one, which is what creators, brands, and affiliate marketers actually need.

## Why TikTok's Built-In Browser Kills Your Conversions

When someone taps a link in TikTok, the app opens it inside a sandboxed browser window. This is not a real browser. It is an isolated container that has no access to the user's saved passwords, payment methods, or login sessions. Here is what that means in practice:

| Problem | What the user experiences |
|---|---|
| Empty login state | They are signed out of every site, including your shop |
| JavaScript restrictions | Automatic redirects to your app are blocked on iOS |

Studies show 88% of mobile time is spent in native apps. Users who land in a native app convert three times better than users stuck in a browser window. Every TikTok link that opens in the built-in browser is costing you that difference.

## The Technical Approach: Detect, Route, Fallback

Getting a link to work properly from TikTok requires four steps working together. We call this the detect-route-fallback method.

### Step 1: Detect TikTok's Browser

TikTok's built-in browser announces itself in the User-Agent string, which you can read with JavaScript:

```javascript
const isTikTokBrowser = /musical_ly|TikTok/i.test(navigator.userAgent);
const isIOS = /iPhone|iPad|iPod/i.test(navigator.userAgent);
const isAndroid = /Android/i.test(navigator.userAgent);
```

Once you know the user is on TikTok's browser, you handle iOS and Android differently.

### Step 2: iOS Routing

Here is the important thing about iOS and TikTok: you cannot automatically redirect someone to your app. iOS WebKit blocks automatic URI launches inside TikTok's browser. The only reliable method is showing the user a button they actually tap themselves.

```html
<!-- This button must be tapped by the user. Auto-redirect will not work on iOS TikTok. -->
<a href="https://yourapp.com/product/123"
   id="open-app-btn"
   style="display:block; padding:16px; background:#ef7a22; color:#fff; text-align:center;">
  Open in App
</a>
```

When the user taps this button, iOS intercepts the `https://yourapp.com` URL and opens your app directly — because your AASA file is already configured. If you haven't set up iOS Universal Links yet, the [iOS Universal Links guide](/blog/ios-universal-links-complete-guide) covers that setup.

### Step 3: Android Routing

Android is more flexible than iOS inside TikTok's browser. You can use an Intent URI which Android handles without requiring a user button tap:

```javascript
if (isAndroid) {
  const intentUri = [
    'intent://yourapp.com/product/123#Intent;',
    'scheme=https;',
    'package=com.yourapp.android;',
    'S.browser_fallback_url=https://play.google.com/store/apps/details?id=com.yourapp.android;',
    'end;'
  ].join('');
  window.location.href = intentUri;
}
```

The `S.browser_fallback_url` parameter at the end is important. It tells Android exactly where to send users who don't have your app installed, so they land on your Play Store page instead of an error.

### Step 4: Set Your Fallbacks

Always have a plan for users without your app installed:

```
iOS fallback:     https://apps.apple.com/app/id[YOUR_APP_ID]
Android fallback: https://play.google.com/store/apps/details?id=[PACKAGE_NAME]
Desktop fallback: https://yourapp.com
```

With these in place, no user ever hits a dead end.

## Linking Into TikTok From Your Own App

If you want to send someone from your app or website to a specific TikTok profile or video, use these URL formats:

```
# Open a TikTok profile
tiktok://user?username=deeplinkos
https://www.tiktok.com/@deeplinkos (fallback if app not installed)

# Open a specific video
tiktok://video?id=7123456789012345678
https://www.tiktok.com/@user/video/7123456789012345678

# Open TikTok's For You page
tiktok://
```

Always pair the `tiktok://` URI with an `https://` fallback URL. The URI scheme only works when TikTok is installed. Without a fallback, users who don't have TikTok see nothing.

## Common Mistakes That Break TikTok Deep Links

### Trying to redirect automatically on page load

```javascript
// This is silently blocked by iOS inside TikTok
window.location.href = "myapp://product/123";
```

This approach does not work on iOS at all inside TikTok's browser. The workaround is to show a button and let the user tap it.

### Using a custom URI scheme without a fallback

Links like `myapp://product/123` only work when the app is installed. When it is not, the user sees an error or nothing at all. Always use `https://` Universal Links as your primary route, and only fall back to the URI scheme as a secondary option.

### Sending TikTok traffic straight to a web checkout

Even if your web checkout looks good on mobile, it will convert at a fraction of the rate a native app screen would. All TikTok traffic should attempt native app launch first and only fall back to web as a last resort.

### No tracking on your TikTok links

A link with no UTM parameters tells you nothing about which video or campaign drove the traffic. Add `?utm_source=tiktok&utm_medium=bio&utm_campaign=campaign-name` to every smart link. For app install attribution, connect to an MMP like AppsFlyer or Adjust through their SDK.

## How to Test Before You Go Live

Always test on real phones. Simulators do not replicate how TikTok's browser actually behaves.

```
Testing checklist:
  [ ] Tap bio link inside TikTok on a real iPhone
  [ ] Tap bio link inside TikTok on a real Android device
  [ ] App installed: should open the correct screen in your app
  [ ] App not installed: should route to the correct App Store
  [ ] Desktop browser tap: should open your web version
  [ ] UTM parameters visible in your analytics dashboard
```

> **Heads up:** TikTok's Android browser is Chrome-based and tends to be more permissive than iOS. A link that works perfectly on Android might still fail on iOS if you haven't set up the interstitial button correctly.

## Frequently Asked Questions

### Do TikTok deep links work for TikTok Shop?

Yes. TikTok Shop product links support deep linking into the TikTok app's native shopping tab. For external stores on Shopify or WooCommerce, you still need the detect-route-fallback approach described above.

### Can I use a link shortener for my TikTok bio?

Yes, but use a branded short domain like `dlnk.co/yourhandle` instead of a generic shortener like `bit.ly`. Branded links get 34% higher click-through rates and are less likely to trigger TikTok's external link warning.

### Why does my link work in Chrome but not inside TikTok?

Chrome is a full browser. TikTok's browser is a sandboxed container with stricter restrictions on JavaScript redirects and Universal Links. The detect-route-fallback method with the interstitial button is designed specifically to solve this gap.

### Do TikTok deep links work in paid ads?

Yes. For ads, configure the Destination URL to your landing page and use the Measurement URL field for your attribution smart link. The routing logic is the same.

### How do I track which TikTok video drove the most app opens?

Create a unique smart link for each video with a different `utm_content` value. DeepLinkOS shows you clicks, device split, and app open rate per link so you can see which videos are actually driving results.
