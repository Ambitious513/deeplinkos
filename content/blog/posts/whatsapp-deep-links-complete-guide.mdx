A WhatsApp deep link is one of the simplest and most effective tools in mobile marketing. When built correctly, a single `wa.me` URL opens a direct chat with your business in under a second, no contact saved, no friction, no steps in between. Built incorrectly, it silently fails, strips your pre-filled message, or sends users to the wrong country code.

This guide covers everything: the correct URL format, the encoding rules that trip people up, how it behaves on iOS vs Android, and how to use WhatsApp links inside QR codes, email campaigns, and social bio pages.

## What Is a WhatsApp Deep Link?

A WhatsApp deep link is a simple HTTPS URL using the `wa.me` domain. When someone taps it, WhatsApp opens automatically and drops them into a new chat with your number, no contact saving required. You can even pre-fill the opening message so they don't have to type anything.

The basic format looks like this:

```
https://wa.me/<number>?text=<url-encoded-message>
```

A real example:

```
https://wa.me/15551234567?text=Hi%2C%20I'd%20like%20to%20know%20more%20about%20your%20services
```

WhatsApp deep links consistently achieve 60 to 98% open rates when sent via SMS or email. Adding a contextual pre-filled message increases chat initiation rates by around 45%. These numbers are hard to match with any other contact method.

## The Number One Mistake: Wrong Phone Number Format

The phone number in your `wa.me` URL must follow E.164 format. This is the international standard and WhatsApp is strict about it. Here is what it means in practice:

| Correct format | Wrong format |
|---|---|
| `15551234567` | `+15551234567` |
| `447911123456` | `+44 7911 123456` |
| `5511987654321` | `(55) 11 98765-4321` |
| `919876543210` | `+91-987-654-3210` |

The rules are simple. Write the country code first, no leading zero. Then write the full number. No plus sign, no spaces, no hyphens, no brackets.

Here are some common countries formatted correctly:

```
USA  +1 (555) 123-4567   becomes   15551234567
UK   +44 7911 123456     becomes   447911123456
Brazil +55 11 9876-5432  becomes   5511987654321
```

## URL Encoding Your Pre-Filled Message

The `text=` parameter in your URL needs to be percent-encoded. Raw text with spaces or special characters will cause the message to be cut off or fail completely.

Here are the most common characters you need to encode:

| Character | What to write instead |
|---|---|
| Space | `%20` |
| Line break | `%0A` |
| `&` | `%26` |
| `=` | `%3D` |
| `?` | `%3F` |
| `,` | `%2C` |
| `'` | `%27` |

Here is a real example. Say you want to pre-fill this message:

```
Hi, I'm interested in your Pro plan.
Order reference: #12345
```

The encoded URL becomes:

```
https://wa.me/15551234567?text=Hi%2C%20I%27m%20interested%20in%20your%20Pro%20plan.%0AOrder%20reference%3A%20%2312345
```

> **Save yourself the headache.** Instead of encoding by hand, use JavaScript's built-in `encodeURIComponent()` function and it handles everything automatically:

```javascript
const phone = '15551234567';
const message = "Hi, I'm interested in your Pro plan.\nOrder: #12345";
const url = `https://wa.me/${phone}?text=${encodeURIComponent(message)}`;
```

## How WhatsApp Links Behave on Different Devices

One of the best things about `wa.me` links is that WhatsApp handles all the routing itself. You do not need to set up any Universal Links or App Links on your own. Here is what happens on each platform:

| Device | What happens | If WhatsApp is not installed |
|---|---|---|
| iPhone | WhatsApp opens instantly via Universal Link | Routes to a download page |
| Android | WhatsApp opens via App Links | Opens Google Play Store listing |
| Desktop Chrome | Opens WhatsApp Web | Prompts WhatsApp Web setup |
| Desktop Safari | Opens WhatsApp Web | Shows a download page |

### Sending Desktop Users to WhatsApp Web Directly

The standard `wa.me` URL on a desktop computer opens an intermediate page that asks users to download WhatsApp or open the web version. If you want to skip that extra step for users who already have WhatsApp Web set up, detect the device and route them directly:

```javascript
const isMobile = /Android|iPhone|iPad|iPod/i.test(navigator.userAgent);
const phone = '15551234567';
const message = encodeURIComponent('Hi, I came from your campaign');

if (isMobile) {
  window.location.href = `https://wa.me/${phone}?text=${message}`;
} else {
  // Skips the intermediate download page for desktop users
  window.location.href = `https://web.whatsapp.com/send?phone=${phone}&text=${message}`;
}
```

> **When to use this:** This is most useful for email campaigns and QR codes where you know a mix of mobile and desktop users will be clicking. For bio links on social media, your audience is almost entirely mobile and the standard `wa.me` URL works perfectly.

## The Four Types of WhatsApp Deep Links

### Click-to-Chat (The Most Common)

```
https://wa.me/15551234567
```

Opens WhatsApp with a new message to that number. No pre-filled text. Good for simple contact buttons where the user will write their own message.

### Click-to-Chat With a Pre-Filled Message

```
https://wa.me/15551234567?text=I%20want%20to%20book%20a%20demo
```

The best option for sales, support, and marketing. A pre-filled message removes the blank page anxiety of starting a conversation, and it tells your team immediately what the person wants when they see the chat come in.

### WhatsApp Group Invite Link

Group deep links use a different format, one that WhatsApp generates for you inside the app:

```
https://chat.whatsapp.com/<invite-code>
```

You generate this inside WhatsApp under Group Info and then Invite Link. You cannot construct it manually.

### WhatsApp Business Catalog Link

If you have a WhatsApp Business account with a product catalog set up:

```
https://wa.me/c/15551234567
```

This opens your catalog directly instead of the chat screen, which is useful for e-commerce and retail businesses running WhatsApp sales.

## Common Mistakes and How to Fix Them

### Putting a plus sign in the phone number

```
https://wa.me/+15551234567   <- This breaks the link
https://wa.me/15551234567    <- This is correct
```

The `+` must not be in the URL. Country code goes straight after `wa.me/` with no symbol before it.

### Spaces in the message text

```
https://wa.me/15551234567?text=Hello World   <- Truncates after "Hello"
https://wa.me/15551234567?text=Hello%20World <- Correct
```

Any raw space in the `text=` value will cut the message off at that point. Always encode spaces as `%20` or use `encodeURIComponent()`.

### Using the old API endpoint

```
https://api.whatsapp.com/send?phone=15551234567  <- Legacy, less reliable
https://wa.me/15551234567                         <- Current standard
```

The `api.whatsapp.com` format still works but is the older approach. Use `wa.me` for all new links.

### Expecting wa.me to start a phone call

WhatsApp does not support a public URL format for voice calls. Calls only happen inside the app. If you need a click-to-call button, use the standard `tel:` protocol instead:

```html
<a href="tel:+15551234567">Call Us</a>
```

## Frequently Asked Questions

### Does wa.me work without the person saving my number first?

Yes, that is the whole point of it. `wa.me` links open a chat without requiring the person to have your number saved in their contacts. It is the frictionless version of sharing your WhatsApp number.

### Can I use wa.me for a WhatsApp Business account?

Yes. The URL format is exactly the same for personal and Business accounts. WhatsApp Business accounts also get the catalog link format (`wa.me/c/[number]`) and the ability to set automated greeting messages that trigger when someone opens a chat.

### How long can the pre-filled message be?

WhatsApp supports up to 65,536 characters per message, but URL length limits are the real constraint. Most browsers cap URLs at around 2,000 characters. Keep your pre-filled messages under 300 characters to stay safe across all platforms and link shorteners.

### Do WhatsApp deep links work inside Instagram and TikTok's built-in browsers?

Usually yes. The `wa.me` Universal Link is respected in most social in-app browsers. But if you need guaranteed reliability across every platform, wrap it in a DeepLinkOS smart link so you can detect the in-app browser and show an explicit "Open in WhatsApp" button when needed.
